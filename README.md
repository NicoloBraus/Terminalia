# Terminalia
Terminalia – IA local Open Source (GGUF/Llama.cpp) que controla terminais Windows, acessa a internet e conversa. Tudo em um só programa, sem Ollama. Código fonte disponível.


**Código fonte disponível** (baixe o ZIP do repositório ou clone).

## O que faz
- Carrega qualquer modelo GGUF compatível com Llama.cpp
- Executa comandos em qualquer terminal do Windows
- Acessa a internet e coleta dados em HTML
- Serve como chat de consulta
- Personalização via arquivos .md (estilo Obsidian): agente, alma, preferências de código, idioma etc.

A criatividade do usuário é o limite.

## Para quem
Desenvolvedores, pessoas criativas, quem trabalha com cibersegurança e curiosos que querem uma IA local poderosa e independente.
